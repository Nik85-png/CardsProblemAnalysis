Power BI Setup

Connect this app to a Power BI push dataset so the dashboard reflects your uploaded data.

1. Azure AD app registration

Create an App Registration in Azure Active Directory:

  • Go to Azure portal > App registrations > New registration.
  • Name it CardsProblemAnalysis-PowerBI and select Accounts in this organizational directory only.
  • Go to Certificates & secrets and create a new client secret. Copy the secret value.
  • Go to Overview and note the Application (client) ID and the Directory (tenant) ID.

2. Enable Power BI service principal access

A Power BI admin must enable service-principal access:

  • Open the Power BI admin portal.
  • Go to Tenant settings and enable Allow service principals to use Power BI APIs.

3. Create a Power BI workspace

  • Create a workspace or open an existing one.
  • Add the Azure AD app as a Contributor or Admin of the workspace.
  • Copy the workspace ID from the URL or workspace settings.

4. Configure the app

Set these environment variables in your .env file or hosting platform:

POWERBI_TENANT_ID=your-tenant-id
POWERBI_CLIENT_ID=your-client-id
POWERBI_CLIENT_SECRET=your-client-secret
POWERBI_WORKSPACE_ID=your-workspace-id
POWERBI_TABLE_NAME=CardsDataset
POWERBI_PUSH_SECRET=choose-a-strong-secret

Optional: set POWERBI_REPORT_EMBED_URL to the embed URL of a report built on the push dataset. You can find this URL under the report's Share → Embed settings in Power BI, or by copying the link from the report page. If omitted, the default shipped report is shown.

5. Create the push dataset

Enter the same push secret from your configuration, then click the button. This reads the current CardsDataset schema and creates a matching push dataset in Power BI.

After the dataset is created, copy the returned dataset id and set it as POWERBI_DATASET_ID, then restart the app.
